# Zaryadka — заряд DualShock

Маленькая программа, которая показывает, насколько заряжен геймпад
**DualShock 4** (а заодно и **DualSense / DualSense Edge**) — по USB и по Bluetooth.

- крупный процент заряда и цветная полоска (зелёная / жёлтая / красная, синяя — при зарядке);
- статус: «от батареи», «заряжается», «заряжен полностью»;
- тип подключения (USB / Bluetooth);
- несколько геймпадов сразу;
- обновление каждые 5 секунд, процент виден в заголовке окна (и на панели задач);
- предупреждение «Пора поставить на зарядку» при заряде ≤ 20 %;
- галочка «поверх окон», чтобы окно не пряталось за игрой.

## Скачать

**Готовый `Zaryadka.exe` для Windows** лежит в разделе
[Releases → latest](../../releases/tag/latest). Скачайте и запустите — Python не нужен.

Exe собирается автоматически (GitHub Actions) при каждом изменении кода.

## Запуск из исходников

Нужен Python 3.9+ ([python.org](https://www.python.org/downloads/), при установке
отметьте «Add Python to PATH»).

### Windows

Дважды кликните **`zaryadka.bat`** — откроется окно. Ничего доустанавливать не нужно:
на Windows программа работает с геймпадом через системные функции, без сторонних библиотек.

Хотите один `.exe` без Python? Запустите **`build_exe.bat`** — получится `dist\Zaryadka.exe`.

### Linux

Драйвер ядра сам отдаёт заряд геймпада, дополнительные библиотеки не нужны:

```bash
python3 -m zaryadka
```

(Для окна нужен tkinter: `sudo apt install python3-tk`. Без него программа работает в консоли.)

### macOS

```bash
pip3 install -r requirements.txt
```

```bash
python3 -m zaryadka
```

### Консольный режим

```bash
python -m zaryadka --cli
```

`--cli` — вывести один раз, `--watch` — обновлять каждые 5 секунд.

## Если геймпад не находится

- Проверьте, что геймпад подключён: по Bluetooth он должен быть сопряжён и
  светиться, по USB — подключён кабелем с передачей данных (а не только зарядным).
- DS4Windows, DSX и подобные программы в «эксклюзивном режиме» прячут геймпад
  от других программ. Отключите эксклюзивный режим или закройте их.
- Если окно не открывается, запустите в консоли `python -m zaryadka --cli` —
  там будет видна ошибка.
- Заряд у DualShock 4 меняется шагами по 10 %, это особенность самого геймпада.

## Как это работает

- **Linux** — читается `/sys/class/power_supply/ps-controller-battery-*`
  (драйвер `hid-playstation`).
- **Windows** — модуль `winhid` читает HID-отчёты геймпада через системные
  `hid.dll` / `setupapi.dll` (ctypes), **macOS** — через `hidapi`. Дальше программа
  разбирает байт состояния батареи (байт 30 в USB-отчёте `0x01`, байт 32 в
  Bluetooth-отчёте `0x11` у DualShock 4; байты 53/54 у DualSense).

Тесты разбора отчётов:

```bash
python -m unittest discover -s tests -t .
```
